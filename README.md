# Use of POSIX services repo

## Repo description

This repo contains a number of introductory examples for using POSIX services.

It is intended for students in our Operating Systems course with no previous
knowledge about the C programming language and/or POSIX.

All the examples make use of the following tools:

1. Docker to run an image with the compiler and other tools.
2. Visual Studio Code as development environment.
3. CMake to configure and build the examples.

## Available examples

For a list of examples, please visit [examples](examples.md).
